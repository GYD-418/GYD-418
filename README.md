## 🛠️ 技术栈

**嵌入式开发**
STM32F1/F4（标准库/HAL）· ESP32/ESP32-S3/C5/P4（ESP-IDF）· MSPM0G3507（TI CCS）· FreeRTOS

**边缘 AI**
K230 CanMV（YOLO 端侧部署 + AI MJPEG Web 服务器）· YOLO 训练与模型转换（.pt → .kmodel/.tflite）· OpenMV

**上位机与云**
Android（Kotlin）· 华为云 IoTDA（MQTT/MQTTS）· Python

**硬件设计与工具链**
嘉立创 EDA 专业版（原理图/PCB/3D 渲染）· SolidWorks · Keil MDK / STM32CubeMX / CLion · Docker · Linux（Debian/WSL/Kali）
